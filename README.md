# Vorn

لعبة تصويب تكتيكية من منظور الشخص الأول، 5 ضد 5 مع بوتات: فريق يزرع القنبلة في النقطة «أ» أو «ب» وفريق يدافع ويفكّكها. أول فريق يصل إلى 5 جولات يفوز.

- الواجهة عربية بالكامل (القوائم، المتجر، لوحة النتائج، الرسائل).
- أزرار لمس للهاتف مع دعم اللمس المتعدد، وتتكيّف مع النوتش وأي مقاس شاشة.
- مبنية بمحرك Godot 4.6.2.

## التحكم على الهاتف

| الزر | الوظيفة |
| --- | --- |
| العصا اليسرى | المشي (ادفعها قليلاً للمشي ببطء) |
| السحب على يمين الشاشة | التصويب |
| زر الإطلاق | إطلاق النار، ويمكن السحب منه للتصويب أثناء الرمي |
| السهمان للأعلى / للأسفل | قفز / انحناء |
| السهم الدائري | تلقيم |
| خانات الأسلحة أسفل الشاشة | تبديل السلاح |
| «المتجر» | الشراء في بداية الجولة |
| «ازرع» / «فكّك» | يظهر عند نقطة القنبلة، اضغط عليه مطولاً |
| أعلى اليمين | إيقاف مؤقت (وفيه حساسية التصويب) ولوحة النتائج |

على الكمبيوتر: WASD والفأرة، B للمتجر، 1/2/3 للأسلحة، R تلقيم، G قنبلة يدوية، E للقنبلة، Tab للنتائج، Esc إيقاف مؤقت.

## نسخة الآيفون

كل تحديث على الفرع `main` يبني ملف `Vorn.ipa` غير موقّع تلقائياً عبر GitHub Actions:

- من تبويب **Actions** ← آخر تشغيل ← **Artifacts** ← `Vorn-iOS`
- أو مباشرة من صفحة **Releases** ← `latest`

ثبّت الملف بأداة تثبيت مثل Sideloadly أو AltStore أو TrollStore.
